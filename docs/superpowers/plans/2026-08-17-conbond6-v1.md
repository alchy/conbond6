# conbond6 v1 — implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Z conbond5 udělat měřitelnou cestu text → interpretovaný graf →
ověřitelná znalost → odpověď viditelná v grafu: statusy výroků
(SAFE/HYPOTHESIS/REJECTED), triáž (podmínka ≠ tvrzení, obsah promluvy ≠ fakt,
disjunkce → zamítnuto), pravidla nad entitami, registr referentů jako projekce
grafu, a **benchmark jako první třída** (yield, precision audit se soudcem
a člověkem, QA s dosahem, audit grafu, regresní diff).

**Architecture:** Jádro conbond5 se přenáší klonem s historií (`cb6 → cb6`).
`memory` dostane druhou osu výroku (`claim`) a export grafu s proveniencí;
`triage` stojí mezi čtením a zakotvením; `discourse.Registry` je pohled nad
hranami `mention`; `bench/` je samostatný balíček, jádro na něm nezávisí.
Každý úkol končí testem, u úkolů měnících jádro také během benche a číslem
v commitu.

**Tech Stack:** Python 3.11, `networkx`; dev `pytest`, `mypy`, `pylint`;
UDPipe služba `127.0.0.1:42200` (conBond3, model `cs_all-ud-2.17-251125`)
jen pro pořízení rozborů a bench; volitelně `anthropic` nebo Ollama pro
soudce auditu.

**Spec:** `docs/superpowers/specs/2026-08-17-conbond6-design.md`

## Global Constraints

- Python `>=3.11`; jediná běhová závislost `networkx>=3.0`; soudce jako extra
  `bench[judge]` (`anthropic`), Ollama přes `urllib` bez závislosti.
- Docstringy česky, bohaté (proč / co / vstup / výstup); pylint 10/10
  u nových modulů (`.pylintrc` v repu).
- Persistence pouze JSON, deterministické id, žádné hodiny ani neseedovaná
  náhoda; „teď“ = číslo tahu; vzorek auditu seedovaný otiskem commitu.
- **I‑1** žádná brána zápisu; **I‑2** yield nikdy tvrzením, které text neřekl;
  **I‑3** hypotéza není znalost (nikdy ve verdiktu); **I‑4** zamítnutí není
  neznalost; **I‑5** každý výrok má `source`; **I‑6** pravdivost neteče po měkké
  hraně; **I‑7** determinismus; **I‑8** nevolit význam kvůli počtu; **I‑9** LM
  není zdroj znalosti; **I‑10** bench před sloučením; **I‑11** paměť je graf a
  nic než graf; **I‑12** odpověď rekonstruovatelná z grafu.
- Testy hermetické: rozbory z `tests/data/parses.json` (`RecordedOracle`);
  nové věty se přidají do `tests/data/sentences.txt` a nahrají
  `python -m cb6.record tests/data/sentences.txt tests/data/parses.json`

- Pole `Statement.status` v conbond5 = životní cyklus (`active|revoked`) —
  **nepřejmenovává se**. Status výroku ze specu (§ 3) je pole **`claim`**
  (`SAFE|HYPOTHESIS|REJECTED`). V grafu i zprávách se mu říká „status“.
- Každý úkol, který mění jádro (Task 6–11), končí: `python -m bench --sada

- [ ] **Krok 3: implementace**

V `Statement` přidat pole `claim: Claim = "SAFE"`, `alternatives: list[str]`,
`rule: str | None = None`, `parent: str | None = None`; `mood` typ
`Literal["assert","question","pattern","reported"]`. `from_json` čte s
výchozími hodnotami. `to_json`/`from_json` `Memory`: `"format":
"conbond6-memory/2"`; `from_json` přijímá i `conbond5-memory/1`.

```python
def knowledge(self) -> Iterator[Statement]:
    """Znalost = to, co smí do verdiktu: aktivní, SAFE, mood assert (I‑3)."""
    for st in self.statements.values():
        if st.status == "active" and st.claim == "SAFE" and st.mood == "assert":
            yield st

def by_claim(self, claim: Claim) -> list[Statement]:
    return [s for s in self.statements.values() if s.status == "active" and s.claim == claim]

def set_claim(self, sid: str, claim: Claim, reason: str) -> None:
    st = self.statements[sid]
    st.claim = claim
    st.defaults.append(f"status → {claim}: {reason}")
    self.version += 1
```

`revoke`: kaskáda přes `other.derived_from == sid` **nebo** `other.parent ==
sid` **nebo** `other.rule == sid`. `by_pred`/`statements_about` zůstávají
(používá je propad); **`logic` v Task 8 přejde na `knowledge()`**.

`ground.py::ground_predication`: vnořená predikace dostane `parent=st.id`
místo `derived_from=parent` (parametr `parent` se přejmenuje na `parent_id`
a plní `parent`). `test_ground.py` upravit tam, kde kontroluje `derived_from`
vnoření (grep `derived_from` v testech).
